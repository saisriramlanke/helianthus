# Helianthic

Android app estimating rooftop solar potential from an address using free, keyless services (US Census and OpenStreetMap geocoding, EU JRC PVGIS), later compared against a physical mini solar panel. See `docs/`.

- `core/` tested TypeScript logic plus a live check: `npm install`, `npm test`, `npm run live-check`
- `android/` Android app (not started)
- `firmware/`, `scripts/` later phases
